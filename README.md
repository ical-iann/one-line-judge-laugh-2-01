A single funny one-liner for the [Make the Judge Laugh in One Line](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21) bounty on make.fun: a tiny deterministic Python program that writes one joke — no longer than 200 characters — to `/output/entry.txt`, where the judge reads it head-to-head against the other entries.

The line: *"I quit my job to follow my dreams. My dreams filed a restraining order, and my landlord co-signed it."*

## Run

```sh
python3 main.py
cat /output/entry.txt
```

No network, no dependencies, no randomness — every run writes the exact same bytes.
